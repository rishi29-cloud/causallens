KNOW THE LIMITS

Explanation is not
a permission slip.

01

Correlation ≠ cause

A model learns patterns in its training examples. A feature can predict an outcome without causing it. This lab shows association, not a causal claim.

02

Attribution is local

These weights explain this particular model near this point. Change the model, inputs, or data distribution and the explanation can change too.

03

Fairness needs context

Even interpretable models can encode unfair histories. Review the data, outcomes across groups, and whether a feature is appropriate for the decision.

UNDER THE HOOD

A transparent model in four moves

  1. NormalizeTurn each input into a comparable number.
  2. WeightMultiply it by a learned coefficient.
  3. SumAdd contributions and a baseline intercept.
  4. SquashUse a sigmoid to map the result to 0–100%.
probability = 1 / (1 + e−(intercept + Σ weight × input))
